# Triage labels

The canonical five-role vocabulary for categorizing issues and pull requests:

| Role | Label string | Purpose |
| :--- | :--- | :--- |
| **Needs triage** | `needs-triage` | Incoming issue or task awaiting initial review and classification |
| **Needs info** | `needs-info` | Blocked on clarification from human, hardware logs, or missing requirements |
| **Ready for agent** | `ready-for-agent` | Fully specified task ready for autonomous agent execution |
| **Ready for human** | `ready-for-human` | Requires physical hardware verification, flashing EVM, or user testing |
| **Won't fix** | `wontfix` | Out of scope, rejected, or obsolete |
